# AI-Assisted Healthcare Provider Data Intelligence Pipeline

## Project Overview
This project is an AI-assisted data intelligence and cleansing pipeline developed for the healthcare domain. It processes raw healthcare provider data, handles missing values, cleans string inconsistencies, and generates structured analytical summaries.

## Key Features
- **Data Cleansing:** Removes whitespace inconsistencies and handles missing contact numbers.
- **Data Intelligence & Analytics:** Categorizes clinics by specialty and aggregates location-specific metrics (e.g., total clinics in Pune).
- **Automated Export:** Generates a standardized, clean CSV dataset for downstream usage.

## Tech Stack
- **Languages & Libraries:** Python, Pandas, NumPy
- **AI Tools Used:** ChatGPT, Claude (for prompt design and code optimization)

## How to Run
1. Clone this repository or download the files.
2. Install Pandas: `pip install pandas`
3. Run the Python script: `python healthcare_data_pipeline.py`
4. View the output in `healthcare_providers_cleaned.csv`.
